shared prompt/schema bugs found + fixed
bug 01

issue/symptoms duplication. Schema asked for the same fact twice — models filled one field, skipped the redundant other. Caused 10 of 23 combined failures across the top two candidates.

fix → _canonicalize_entities() backfills both directions deterministically
bug 02

no time-of-day convention. "tomorrow morning" has no exact hour — models correctly returned the literal word, since none was defined.

fix → prompt defaults: morning=09:00, afternoon=14:00, evening=18:00, night=20:00
bug 03

stale context override. DeepSeek kept an old turn's issue after a later turn explicitly changed it.

fix → explicit "new message wins" rule added to system prompt
